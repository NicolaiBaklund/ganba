# Form (dagstall på Recovery) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Form (0–100) øverst på Recovery og liten ring på forsiden. Faste regler mot egen normal, lærte deler fra statistikkmotoren, mal- eller AI-setning og coach-handling. Recovery-siden bygges om for å kunne leses på et blikk.

**Architecture:** Ren motor i `packages/core/src/recovery/form.ts` (deler, Form per dag, selvsjekk, ukebalanse) på `RecoveryDayInput` utvidet med valgfrie felt. `computeRecovery` regner ut og lagrer `form_days` for 90-dagersvinduet etter funnene. `lib/recovery/form.ts` laster visningen. AI-setningen går gjennom eksisterende `RecoveryAi` og `recovery_day_answers` (`question = 'form'`).

**Tech Stack:** Next.js 16, next-intl, Tailwind 4 (Tasuki-tokens), recharts, Supabase, `@anthropic-ai/sdk`, zod v4, Vitest, Playwright.

**Spec:** `docs/specs/2026-10-05-form.md`

## Global Constraints

- Ingen enhetstester/TDD. Integrasjonstester i `tests/integration/` etter at koden står.
- Ingen `Co-Authored-By`/Claude-attribusjon i commits. Aldri `git add -A`.
- Gren `form`. Ikke push/merge uten at brukeren ber om det.
- DB: ny migrasjon + `pnpm db:push`. Rent additiv.
- UI på engelsk. Ingen tankestreker, ingen «·»-kjeder, ingen etiketter i store bokstaver. Tasuki-tokens. Ringen tegnes i SVG (ingen gradienter).
- Samtykke: helsebryter av → null AI-kall. Malsetningen virker alltid.
- Systemet er flerbruker: ingen hardkodede personlige verdier.

## Review Focus

1. **Ingen natt i dag** (klokka av): Form null, grå ring «–», forsiden viser ingen ring, ingen krasj. Test i Task 1 (motor) og Task 3 (view).
2. **Ny bruker med få dager**: hvilepuls uten 14 verdier, belastning uten 21 dager, søvnbehov mangler → delene `missing`, tallet regnes av resten. Test i Task 1.
3. **Ekstremverdier** (HRV 3× normal, 0 t søvn, underskudd 3000): poeng holder seg innenfor taket, Form innenfor 0–100. Test i Task 1.
4. **AI-svar med oppdiktede henvisninger** eller bryter av midt i bruk: setningen faller tilbake til malen, og det gjøres ingen AI-kall uten samtykke. Test i Task 4.
5. **Hard økt allerede gjennomført i dag**: knappen «Make today easier» vises ikke. Test i Task 3 (view-flagget `action`).
