# Loop — web app

Next.js (App Router) PWA for Loop: nutrition, weight trend and adaptive calorie targets.

- Run from the repo root: `pnpm dev`, `pnpm typecheck`, `pnpm build`, `pnpm test:int`
- Environment: copy `../../.env.example` to `.env.local`
- Domain logic lives in `packages/core`; see the root `CLAUDE.md` and `docs/` for specs and decisions.

Deployed on Vercel with Root Directory `apps/web`.
