# Loop — kontekst for Claude

**Fase nå:** konsept for fase 1 (mat + vekt) skrevet, venter på brukerens gjennomlesing. Neste: teknisk design. Ingen kode før teknisk spec + plan er godkjent.

Systemet er **generelt/flerbruker** — aldri hardkod brukerens personlige verdier.
